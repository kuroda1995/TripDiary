# 05. コメント（CMT）

| 項目 | 内容 |
| --- | --- |
| 機能ID | CMT-01 〜 CMT-05 |
| 関連テーブル | `comments` |
| 関連資料 | [要件定義書 3.5](../requirements.md#35-コメントcomment) |

---

## 1. 概要

スポットにコメントを投稿して、投稿者や他のユーザーと交流できる機能です。

### 実装状況

| 項目 | 状況 |
| --- | --- |
| 投稿・一覧・編集・削除・件数表示（CMT-01〜04） | 実装済み |
| 返信（スレッド、CMT-05） | 将来対応 |

## 2. ユーザーストーリー

- ユーザーとして、気になるスポットについて投稿者に質問したい（例: 「何時ごろ行きましたか？」）。
- ユーザーとして、自分のコメントの誤字を直したり削除したりしたい。
- 投稿者として、自分の投稿についた不適切なコメントを削除したい。

## 3. 画面・UI

- スポット詳細画面の下部にコメント一覧（古い順）と入力欄を表示します。
- コメントが多い場合は「さらに表示」で続きを読み込みます。
- 自分のコメントには「編集」「削除」、自分の投稿についたコメントには「削除」メニューを表示します。
- 編集されたコメントには「（編集済み）」と表示します。
- 入力欄には残り文字数を表示します。
- 未ログイン時は入力欄の代わりに「ログインしてコメントする」ボタンを表示します（ログイン後に元の画面へ戻る）。
- 削除は確認ダイアログを出します。失敗したらダイアログを閉じてトーストで知らせます。
- 投稿・編集・削除の後は、コメント一覧とスポットのコメント件数を取り直します。
- スポットカードにはコメント件数を表示します。

## 4. API 仕様

| メソッド | パス | 認証 | 概要 |
| --- | --- | --- | --- |
| GET | `/spots/{id}/comments` | 不要 | コメント一覧（古い順・カーソルページング） |
| POST | `/spots/{id}/comments` | 必要 | コメント投稿 |
| PATCH | `/comments/{commentId}` | 必要（コメント投稿者） | コメント編集 |
| DELETE | `/comments/{commentId}` | 必要（コメント投稿者 または スポット投稿者） | コメント削除 |

### 4.1 投稿 `POST /spots/{id}/comments`

リクエスト: `{ "body": "何時ごろ行きましたか？" }`

レスポンス `201 Created`:

```json
{
  "id": 501,
  "spotId": 1024,
  "body": "何時ごろ行きましたか？",
  "author": { "id": 7, "username": "hanako", "displayName": "はなこ", "avatarUrl": null },
  "edited": false,
  "createdAt": "2026-11-11T03:00:00Z",
  "updatedAt": "2026-11-11T03:00:00Z"
}
```

### 4.2 一覧 `GET /spots/{id}/comments?cursor=&limit=20`

```json
{ "items": [ { "id": 501, "body": "...", "...": "..." } ], "nextCursor": null }
```

- 未ログインでも閲覧できます（他人の非公開スポットは 404）。
- `nextCursor` は「最後に返したコメントの投稿日時と ID」を Base64URL でエンコードした文字列です。
- スポットの詳細・一覧 API には `commentCount` を含めます（行ってみたい！数と同じ1回の SQL でまとめて取得）。

### 4.3 編集 `PATCH /comments/{commentId}` / 削除 `DELETE /comments/{commentId}`

- 編集: `{ "body": "修正後の本文" }` → `200 OK`（更新後のコメント）
- 削除: `204 No Content`

## 5. 業務ルール・バリデーション

| 項目 | ルール |
| --- | --- |
| 本文 | 必須、1〜1,000文字、前後の空白は除去。空白のみは不可 |
| 表示 | プレーンテキストとして表示（HTML・スクリプトは実行しない）。改行は保持 |
| 編集 | コメント投稿者本人のみ（スポットの投稿者でも他人のコメントは編集不可）。`updatedAt` が `createdAt` と異なる場合 `edited: true`。同じ本文で保存した場合は `updatedAt` を変えない |
| 日時 | 作成時に `createdAt` と `updatedAt` に同じ値を入れる（DB の自動設定に任せると別々の時刻になり、作成直後から「編集済み」になるため）。DB の精度（マイクロ秒）に切り捨てて保存する |
| 削除 | コメント投稿者本人、またはコメントが付いたスポットの投稿者 |
| 非公開投稿 | 本人以外は閲覧・投稿不可（404 `SPOT_NOT_FOUND`）。他人の非公開スポットのコメントの編集・削除は、存在を知られないよう 404 `COMMENT_NOT_FOUND` |
| 並び順 | 古い順（`createdAt` 昇順、同時刻は `id` 昇順） |
| 削除連動 | スポットまたはユーザーが削除されると自動削除 |

## 6. 関連テーブル

| テーブル | 用途 |
| --- | --- |
| `comments` | コメント本体（`spot_id`, `user_id`, `body`） |

## 7. エラーコード

| HTTP | コード | 発生条件 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 空文字・1,001文字以上 |
| 401 | `UNAUTHORIZED` | 未ログインで投稿・編集・削除 |
| 403 | `FORBIDDEN` | 権限のない編集・削除 |
| 404 | `SPOT_NOT_FOUND` | スポットが存在しない、または他人の非公開投稿 |
| 404 | `COMMENT_NOT_FOUND` | コメントが存在しない、または他人の非公開スポットのコメント |
| 400 | `INVALID_CURSOR` | 一覧のカーソルの形式が不正 |
