# 12. テーマ別コミュニティ（GRP）

| 項目 | 内容 |
| --- | --- |
| 機能ID | GRP-01 〜 GRP-07 |
| 関連テーブル | `communities`, `community_members`（V9）、`board_topics.community_id`（V9 で追加） |
| 関連資料 | [10_community_board.md](10_community_board.md)（トピック・返信の仕組み） |

---

## 1. 概要

ユーザーが「北陸・富山のお寺巡り同好会」「限定御朱印情報シェアの会」のようなテーマ別のコミュニティ（サークル・グループ）を作り、他のユーザーが参加して交流できる機能です。コミュニティの中では、メンバー同士がトピックを立てて返信し合えます（内輪トーク）。

誰でも書き込める「お寺コミュニティ広場」（[10_community_board.md](10_community_board.md)）とは別に、テーマに興味のある人だけが集まって話せる場所を用意します。

| ID | 内容 |
| --- | --- |
| GRP-01 | コミュニティの作成（名前・説明文・カテゴリタグ） |
| GRP-02 | コミュニティの一覧・検索（キーワード・カテゴリ、新着順・人気順） |
| GRP-03 | コミュニティの詳細（オーナー・メンバー数・トピック数） |
| GRP-04 | 参加・退出（ワンクリックで切り替え） |
| GRP-05 | メンバー一覧 |
| GRP-06 | コミュニティ内のトピック・返信（メンバーのみ書き込める） |
| GRP-07 | コミュニティの削除（オーナーのみ） |

## 2. ユーザーストーリー

- 参拝者として、自分の住む地域のお寺に詳しい人とつながり、地元ならではの情報を交換したい。
- 御朱印を集めている人として、同じ趣味の人だけで限定御朱印の情報を共有したい。
- お寺巡りを始めたばかりの人として、「初心者歓迎」のコミュニティを探して気軽に質問したい。
- コミュニティの作成者として、テーマに合わない書き込みを削除して場を整えたい。

## 3. 画面・UI

| 画面 | パス | 主な要素 |
| --- | --- | --- |
| コミュニティ一覧 | `/communities` | 説明文、「コミュニティを作る」（未ログインは「ログインしてコミュニティを作る」）、キーワード検索、カテゴリの絞り込み（「すべて」と各カテゴリのボタン。1つだけ選べる）、並び順（新着順 / メンバーが多い順）、カード（名前・カテゴリ・説明文の先頭・メンバー数・作成者・「参加中」、「もっと見る」） |
| コミュニティ作成 | `/communities/new`（要ログイン） | コミュニティ名、説明文（残り文字数）、カテゴリ（チェックボックス・1つ以上） |
| コミュニティ詳細 | `/communities/:id` | 名前・カテゴリ・説明文・オーナー・メンバー数・トピック数・作成日時、「コミュニティに参加する / 退出する」（未ログインは「ログインして参加する」、オーナーは出さず「コミュニティを削除」）、メンバーのトピック（メンバーには作成フォーム、メンバー以外には参加の案内）、メンバー一覧（参加した順・オーナーに「オーナー」） |
| トピック | `/community/topics/:id` | 広場と同じ画面。コミュニティのトピックでは「← コミュニティ名」で戻れ、返信フォームはメンバーにだけ出す（メンバー以外には参加の案内）。オーナーにはトピック・返信の削除ボタンを出す |

- ヘッダーのメインナビゲーションに「コミュニティ」を置きます（狭い画面ではアイコンだけ。読み上げ名は常に「コミュニティ」）。
- 検索条件は URL のクエリ（`?q=富山&category=REGIONAL&sort=popular`）に持ち、共有・ブラウザの戻る操作に対応します。
- 説明文・本文はプレーンテキストとして表示し、改行を保持します（HTML は解釈しない）。
- 参加・退出したら結果をトーストで知らせ、メンバー数とボタンをすぐに切り替えます。

## 4. API 仕様

| メソッド | パス | 認証 | 概要 |
| --- | --- | --- | --- |
| GET | `/communities?q=&category=&sort=newest\|popular&cursor=&limit=20` | 不要 | 一覧・検索 |
| POST | `/communities` | 必要 | 作成（201・`Location`）。作成者はオーナーとして自動で参加 |
| GET | `/communities/{id}` | 不要 | 詳細（ログイン中なら `joined` を返す） |
| DELETE | `/communities/{id}` | 必要 | 削除（オーナーのみ。メンバー・トピック・返信も削除） |
| PUT | `/communities/{id}/membership` | 必要 | 参加（冪等） |
| DELETE | `/communities/{id}/membership` | 必要 | 退出（冪等。オーナーは 409） |
| GET | `/communities/{id}/members?cursor=&limit=20` | 不要 | メンバー一覧（参加した順） |
| GET | `/communities/{id}/topics?cursor=&limit=20` | 不要 | コミュニティ内のトピック一覧（最後に書き込みがあった順） |
| POST | `/communities/{id}/topics` | 必要 | トピック作成（メンバーのみ。201・`Location`） |

トピックの詳細・返信一覧・返信・削除は広場と同じ API（`/board-topics/{id}`、`/board-topics/{id}/replies`、`/board-replies/{id}`）を使います。

### 4.1 一覧・検索 `GET /communities`

| パラメータ | 内容 |
| --- | --- |
| `q` | 名前・説明文の部分一致（前後の空白は除く。最大100文字。`%`・`_` は文字として扱う） |
| `category` | カテゴリ（1つ）。指定したカテゴリを持つコミュニティに絞る |
| `sort` | `newest`（新着順。既定）/ `popular`（メンバー数の多い順。同数は新しい順） |

```json
{
  "items": [
    {
      "id": 3,
      "name": "北陸・富山のお寺巡り同好会",
      "descriptionExcerpt": "国宝・瑞龍寺や勝興寺など、…",
      "categories": ["REGIONAL", "BEGINNER_FRIENDLY"],
      "owner": { "id": 2, "username": "kenta_camera", "displayName": "カメラ好きのケンタ", "avatarUrl": null, "badge": "MASTER" },
      "memberCount": 3,
      "joined": true,
      "createdAt": "2026-11-20T03:00:00Z"
    }
  ],
  "nextCursor": null
}
```

### 4.2 作成 `POST /communities`

リクエスト: `{ "name": "...", "description": "...", "categories": ["REGIONAL", "BEGINNER_FRIENDLY"] }`。

レスポンス（詳細 `GET /communities/{id}` と同じ形）:

```json
{
  "id": 3,
  "name": "北陸・富山のお寺巡り同好会",
  "description": "国宝・瑞龍寺や勝興寺など、…",
  "categories": ["REGIONAL", "BEGINNER_FRIENDLY"],
  "owner": { "id": 2, "username": "kenta_camera", "displayName": "カメラ好きのケンタ", "avatarUrl": null, "badge": "MASTER" },
  "memberCount": 1,
  "topicCount": 0,
  "joined": true,
  "createdAt": "2026-11-20T03:00:00Z"
}
```

### 4.3 参加・退出 `PUT / DELETE /communities/{id}/membership`

レスポンス: `{ "communityId": 3, "joined": true, "memberCount": 4 }`

### 4.4 メンバー一覧 `GET /communities/{id}/members`

```json
{
  "items": [
    { "user": { "id": 2, "username": "kenta_camera", "displayName": "カメラ好きのケンタ", "avatarUrl": null, "badge": "MASTER" }, "owner": true, "joinedAt": "2026-11-20T03:00:00Z" }
  ],
  "nextCursor": null
}
```

### 4.5 トピック詳細（広場の API に追加した項目）

`GET /board-topics/{id}` などのトピック詳細に `community` を追加しました。広場のトピックは `null` です。

```json
{ "community": { "id": 3, "name": "北陸・富山のお寺巡り同好会", "ownerId": 2 } }
```

## 5. 業務ルール・バリデーション

| 項目 | ルール |
| --- | --- |
| コミュニティ名 | 1〜50文字（前後の空白を除く）。同じ名前は作れない（英字の大文字・小文字は区別しない） |
| 説明文 | 1〜1000文字（前後の空白を除く） |
| カテゴリ | 1つ以上。`REGIONAL`（地域別）/ `GOSHUIN`（御朱印）/ `ARCHITECTURE_GARDEN`（建築・庭園）/ `BEGINNER_FRIENDLY`（初心者歓迎）/ `PHOTOGRAPHY`（写真・撮影）。重複は1つにまとめ、この順に並べる |
| 編集 | 提供しない（将来検討） |
| オーナー | 作成者。作成時に自動で参加する。退出できない（やめるときはコミュニティを削除する） |
| 参加・退出 | ログインしていれば誰でも参加できる（承認制ではない）。どちらも冪等 |
| 閲覧 | コミュニティ・メンバー・トピック・返信は、メンバー以外・未ログインでも見られる |
| 書き込み | コミュニティ内のトピック作成・返信はメンバーのみ。退出すると書き込めなくなる（書いたものは残る） |
| 削除 | コミュニティ: オーナーのみ。トピック: 作成者またはオーナー。返信: 投稿者・トピックの作成者・オーナー |
| 削除連動 | コミュニティを削除するとメンバー・トピック・返信も削除。オーナーのユーザーが削除されるとコミュニティも削除。メンバーのユーザーが削除されると参加も外れる |
| メンバー数 | オーナーを含む。`community_members` のトリガーで `communities.member_count` を保つ |
| コミュニティ称号 | コミュニティ内のトピック・返信も、掲示板の書き込みとして称号（[11_community_reactions.md](11_community_reactions.md)）の件数に含まれる |

## 6. 関連テーブル

| テーブル | 用途 |
| --- | --- |
| `communities` | コミュニティ（オーナー・名前・説明文・カテゴリ・メンバー数） |
| `community_members` | 参加関係（ユーザーとコミュニティの中間テーブル。主キー `(community_id, user_id)`） |
| `board_topics` | `community_id` が入っているトピックがコミュニティ内のトピック。`NULL` は広場 |
| `board_replies` | 返信（広場と共通） |

コミュニティ内のトピックを別テーブルにせず `board_topics` に `community_id` を足したのは、返信・削除・一覧・称号の件数の仕組みをそのまま使えるためです。広場の一覧は `community_id IS NULL` の部分インデックスで読みます。

## 7. エラーコード

| HTTP | コード | 発生条件 |
| --- | --- | --- |
| 400 | `VALIDATION_ERROR` | 名前・説明文が空や長すぎる、カテゴリが空・不明、キーワードが長すぎる、並び順が不明 |
| 400 | `INVALID_CURSOR` | カーソルの形式が不正 |
| 401 | `UNAUTHORIZED` | 未ログインで作成・参加・退出・書き込み・削除 |
| 403 | `FORBIDDEN` | オーナー以外のコミュニティの削除、権限のないトピック・返信の削除 |
| 403 | `COMMUNITY_MEMBERSHIP_REQUIRED` | メンバー以外がコミュニティ内でトピック作成・返信 |
| 404 | `COMMUNITY_NOT_FOUND` | 存在しないコミュニティ（詳細・参加・メンバー・トピック） |
| 409 | `COMMUNITY_NAME_TAKEN` | 同じ名前のコミュニティがある |
| 409 | `OWNER_CANNOT_LEAVE` | オーナーが退出しようとした |

## 8. テスト観点

- 作成（空白の除去・カテゴリの整列・オーナーの自動参加・Location）、同名の拒否、入力エラー、未ログインの拒否（`CommunityIntegrationTest`）
- 一覧（新着順・参加中）、キーワード（名前・説明文、`%` を文字として扱う）、カテゴリ、人気順とカーソル、不正なカーソル・並び順
- 参加・退出の冪等性とメンバー数、オーナーは退出できない、メンバー一覧の順番とカーソル
- コミュニティ内のトピックが広場に出ないこと、メンバー以外の書き込み拒否（参加・退出で切り替わる）、オーナーによる削除
- コミュニティの削除の権限と連鎖削除、ユーザー削除時のメンバー数と連鎖削除
- カテゴリの整列・オーナー判定・カーソル・トピックの管理者判定（`CommunityTest`）
- 画面: ナビゲーション、一覧の表示、検索条件と URL、作成と画面遷移、入力エラー・同名エラー、詳細、参加・退出、メンバーのトピック作成、オーナーの削除、コミュニティのトピックでの返信の出し分け（`communities.test.tsx`）、E2E（`e2e/communities.spec.ts`）

## 9. 補足・将来検討

- コミュニティの編集（名前・説明文・カテゴリ）、アイコン画像。
- 承認制・招待制（非公開コミュニティ）、オーナーの交代・副管理者。
- マイページの「参加中のコミュニティ」一覧、新しいトピックの通知。
- 通報・管理者による削除。
